Digital Logs Privacy Policy

Effective Date: August 22, 2026

This privacy policy applies to the Digital Logs application. This document outlines data collection, usage, and sharing practices for the application.

1. Data Collection

Digital Logs does not collect, transmit, or store personal information on external servers. All data generated by the application remains entirely on the local device.

To provide core functionality, the application requests the following device permissions:

  • Microphone Access: Required strictly to create audio recordings within the application.

2. Data Usage

Audio recordings are used exclusively to provide features within Digital Logs. All generated files are stored locally in the application's storage on the device. Data is not used for tracking, analytics, or marketing.

3. Data Sharing

The application does not transmit data to external servers, and data is not sold, traded, or shared with outside parties. The application provides the ability for the user to manually export data to a file.

4. Policy Updates

This Privacy Policy may be updated periodically. Any changes will be reflected by updating the "Effective Date" at the top of this document.
