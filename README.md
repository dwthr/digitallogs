# Digital Logs
> A simple application for creating timestamped entries. 
> <br>
> 
> It currently supports text and audio recordings.

## About
This is the first app I have ever made. I had no experience in Android before starting this project. It was created with Jetpack Compose with Material Design.
<br>

If you are looking through the code and notice a lot of confusing TODO comments, they were made before I planned on releasing the code publicly; Some already have been solved or are irrelevant now.

### Future plans
I don't plan on updating the code much beyond this unless interest is shown in the project. 

If there is, I will complete the TODOs before I make any new plans. Top priorities would be data backups verification, search, and new entry types.

## Installation
You will have to build the project from source as of now. 

I plan on releasing a build on Google Play if enough people are interested. That's why you'll see a [privacy.html](privacy.html) in the project directory.
